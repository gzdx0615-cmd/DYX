# X·抖音保存

一个原生 Apple 快捷指令，自动识别 X/Twitter 帖子和抖音作品，解析并保存到相册。

当前合并版已于 **2026-11-27 获得用户实际使用可用的反馈**。使用时不需要安装独立的 X 或抖音快捷指令。

## 支持功能

| 平台 / 内容 | 保存方式 |
| --- | --- |
| X / Twitter 公开视频 | 保存帖子的第一条视频 |
| 抖音视频 | 保存接口返回的视频 |
| 抖音普通图集 | 逐张保存全部图片 |
| 抖音实况素材 | 分别保存照片和动态视频，不合成 Apple Live Photo |

分享菜单与剪贴板均可使用：从 X 或抖音的系统分享菜单运行，或复制链接 / 分享文案后直接运行。分享输入优先；没有输入时读取剪贴板。一段文案包含多个支持的链接时，只处理第一条。

## 安装

需要一台支持「快捷指令」App 的 Mac 来签名导入，然后同步或分享到 iPhone。无需安装 Python 或其他依赖。

在 Mac 终端运行：

```bash
curl -fL https://v4.gh-proxy.org/https://raw.githubusercontent.com/gzdx0615-cmd/DYX/main/install-unified-mac.sh -o /tmp/dyx-install-unified.sh && /bin/bash /tmp/dyx-install-unified.sh
```

这是固定版本的安装命令，避免代理缓存使你下载到旧文件。安装脚本还会校验源文件 SHA-256，再调用苹果 `shortcuts sign --mode anyone` 并打开导入窗口。源文件优先通过 GitHub 代理下载，失败或校验不一致时尝试直连。

1. 导入为 **X·抖音保存**；如果已有旧合并版，选择替换。
2. 在 Mac 快捷指令 App 中选择「分享 → 拷贝 iCloud 链接」，在 iPhone 打开并添加；也可使用同一 Apple 账号的 iCloud 同步。
3. 更新后应重新生成 iCloud 分享链接；旧分享链接不会自动替换成新版动作。
4. 首次运行时，按系统提示允许联网和添加照片。

仓库中的 `X-Douyin-unsigned.shortcut` 是可审查的未签名 XML 源文件，不能直接作为 iPhone 安装包使用。iCloud 安装链接需要在用户的苹果设备中生成，仓库不提供未经生成的分享链接。

## 日常使用

- **复制运行**：复制 X 帖子链接或抖音作品的整段分享文案，再运行「X·抖音保存」。
- **分享运行**：在 X 或抖音的系统分享面板中选择「X·抖音保存」。
- 如果分享面板没有显示它，检查详情中的「在共享表单中显示」，并在系统分享面板的「编辑操作」中添加。
- 实况素材会先提示：照片和动态片段将分别保存。它们不是相册中可长按播放的 Live Photo；可以取消保存。

当前识别 `x.com/.../status/...`、`twitter.com/.../status/...`、`v.douyin.com/...`、`douyin.com/video/...` 和 `iesdouyin.com/share/video/...`。不支持受保护帖子、直播或其他未列出的链接类型。

## 平台隔离与服务依赖

先在设备上识别链接，再进入对应分支，没有所有平台共用的联网初始化步骤。

- **X**：使用 FxTwitter 解析，不读取 GitHub 上的抖音配置，也不调用抖音接口。
- **抖音**：通过 GitHub 代理读取本仓库的配置，再调用抖音解析接口，不调用 FxTwitter。

因此，抖音配置或服务不可用时不会阻止 X 分支运行；X 接口不可用也不会阻止下一次运行抖音分支。相册权限、设备网络和系统错误属于两边共同依赖的设备条件。

配置保存在本仓库，但解析服务仍由第三方提供；托管 JSON 不等于自建解析服务器。

抖音配置原始地址：

```text
https://raw.githubusercontent.com/gzdx0615-cmd/DYX/main/douyin.json
```

快捷指令实际读取的代理地址：

```text
https://v4.gh-proxy.org/https://raw.githubusercontent.com/gzdx0615-cmd/DYX/main/douyin.json
```

代理只用于读取 GitHub 配置和安装文件，不代理抖音解析请求或视频下载。代理和解析服务均可能变化或暂时不可用。运行时会向对应解析服务发送所选的公开作品链接，不上传整段剪贴板内容。

修改 `douyin.json` 后，下一次抖音运行会请求该配置，但代理可能有缓存。修改动作流程或修复参数连接时，需要重新签名、导入并同步快捷指令。

## 文件与维护

| 文件 | 用途 |
| --- | --- |
| `X-Douyin-unsigned.shortcut` | 当前合并版的原生 XML 源文件 |
| `install-unified-mac.sh` | 合并版 Mac 签名导入脚本，固定源文件提交并校验 SHA-256 |
| `build_unified.py` | 从独立源文件生成合并版，仅维护时需要 Python |
| `X-Working-unsigned.shortcut` | 用户提供并确认可用的独立 X 参考流程 |
| `Douyin-unsigned.shortcut` | 支持视频、图集及实况素材分别保存的独立抖音流程 |
| `douyin.json` | 抖音远程配置 |
| `check_unified.py` | 动作结构、平台分流及故障隔离的离线检查 |
| `check_unified_online.py` | 按动作数据模拟运行、请求实际接口并校验媒体文件 |
| `validation/` | 测试范围、历史网络结果及已知限制 |
| `CHANGELOG.md` | 更新记录 |

独立版 X、抖音源文件和安装脚本仍保留，合并版无需调用或另行安装它们。

维护时，重新生成源文件后应同时更新安装脚本中的不可变提交地址和 SHA-256，以及本页的固定安装命令。

## 验证范围

用户已反馈当前修正版可以使用；未记录具体设备和 iOS 版本，因此不代表所有系统与网络环境均已验证。

自动检查覆盖分享 / 剪贴板路由、分享输入优先、图集循环、无效链接、第一条链接选择及两平台的服务故障隔离。实际网络检查曾完成 X 视频、抖音视频、4 张图集图片和 4 组实况素材的下载与文件校验。后续一次云端 X 视频下载返回 403，表明网络可用性会变化。

自动测试运行在 Linux 上的动作数据模拟中，不是苹果快捷指令执行引擎，不能替代 iPhone 分享菜单、权限和相册写入测试。详见 [验证说明](validation/README.md)。

## 测试数据隐私

公开测试脚本仅使用虚构样例。真实作品链接、账号、作品标题和逐条下载记录不应提交到仓库。在线测试通过 `--private-cases` 读取仓库外的本地文件；请勿上传该文件或本地下载目录。
