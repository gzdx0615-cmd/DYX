2026-11-27，用户在安装使用“原始链接包含 `/status/`”分流的修正版后，反馈“可以用了”，并要求更新到 GitHub。该修正版作为当前合并版发布。未记录具体设备和系统版本；反馈不能扩展成所有 iOS 版本、网络和内容均已验证。

## 当前实现

先匹配受支持的链接并提取第一条，将其转换成文本并保存为「待解析链接」。使用原生 contains 条件（99）直接检查原始链接中的 `/status/`，有则进入 X/Twitter 分支，无则进入抖音分支。比较参数为原生文本格式，不再通过正则替换生成平台标记。

X 动作来自用户提供并确认可用的独立 X 快捷指令；下载 URL 保留原生文本参数格式。抖音的图集和实况素材循环使用 Apple 内置 Repeat Item 变量格式。

## 已完成检查

## 网络验证与限制

此前曾按生成动作的数据流模拟执行，并实际请求接口、下载和校验：X 视频、抖音视频、4 张图集图片、4 张实况照片和 4 段动态视频。分享和剪贴板各一组，共 8 条数据路径，公开仓库不再保留逐条下载记录，仅保留不含个人样本标识的验证说明。

最新一次完整在线回归在 X 视频 CDN 返回 HTTP 403 时中止，尽管 FxTwitter 解析接口返回 HTTP 200；因此不能把历史 8 条下载成功说成最新一次也全部成功，或保证接口长期可用。详见 [当次检查说明](status-path-routing.md)。

自动检查是在 Linux 的动作数据模拟中运行，不是苹果快捷指令执行引擎；真实设备的分享菜单、签名导入、权限和相册写入只能依据用户设备反馈。
