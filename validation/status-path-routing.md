# 原始链接分流修正

用户反馈上一候选抖音已可用，X 运行时尝试读取 `data`。最新候选移除平台标记替换操作，直接检查已匹配的受支持原始链接是否包含 `/status/`，使用原生 contains 条件（99）及 WFTextTokenString 比较参数。允许的 X/Twitter 帖子路径包含此段，允许的抖音作品路径不包含。

已通过源文件结构、两种输入、分享优先、两平台服务故障隔离及原始链接分流的离线回归检查。安装脚本与不可变源文件的校验值匹配。

本轮真实网络检查：FxTwitter 返回 HTTP 200 和有效视频地址；当前云端请求该视频 CDN 返回 HTTP 403，因此本轮完整在线下载回归中止，不能声称本轮 8 条路径全部下载通过。仓库此前的 8 路径报告是历史测试结果，不代表这个版本已在 iOS 运行。

需要用户在 iPhone 上确认 X 的分享和剪贴板运行。抖音的解析和保存动作未改动。仍不宣称 iOS 全链路已验证。
